# 电子书分享阅读统计

Date: 2026-11-05  
Product: family-mediacenter  
Status: approved

## Goal

分享阅读页按设备记录阅读时长、作息和哪本书被打开。查询与视频观看统计分开。设备标识与视频共用，设备允许开关不拦截阅读。

## Identity

- 继续使用 `share_devices` 和一年期 cookie `fmc_visitor`。同一浏览器里，看视频和读电子书是同一台设备。
- 打开分享阅读页时新建一条阅读访问。会话 cookie `fmc_read_visit` 指向这一次打开。
- 不改视频使用的 `fmc_visit`。
- 不做读者命名。查询结果按设备名、IP 和 User-Agent 分开。
- 新设备默认 `allowed=true`。已有设备的 `allowed` 保持原值。这个开关和视频共用：关掉后，这台设备打不开分享书架、阅读页和书的文件，页面显示「这台设备未允许」。已经记下的阅读记录仍保留。管理页里的预览不检查这个开关。

## Where it records

只在这两个页面记录：

- `/shelf/{token}/read`
- `/book/{token}`

只打开书架 `/shelf/{token}`，或在管理页里预览阅读，都不记，也不写 `fmc_read_visit`。

书的标识是书库内路径。书架里的书是「分享目录 + 相对路径」，单本分享就是该分享的 `sub_path`。同一本书从书架或单本链接打开，统计里算一本。标题在写入时留下文件名快照。不记页码，也没有读完次数。

## Recording

阅读页在前台时上报 `POST /api/v1/share/read/{token}/stats`。这个地址不需要 API Key。

- `open`：这次阅读访问的第一次打开加 1。同一访问里之后的 `open` 不再累加。页面在后台打开时先不发，直到变为前台再发这一次。请求带上打开页面时的 `visit_id`，避免同一浏览器再开另一本书时，把旧页面的时间记到新书上。
- `tick`：`delta_sec` 在 `(0, 15]` 时计入阅读秒数，并落到服务器本地时间的日期和小时。超出范围不加时长，接口仍返回成功。一次只上报一段，剩余时间留到下一次。距上次心跳超过 20 秒视为页面被挂起，这段不计入。

前台用实际经过的时间累计。满 15 秒，或在切走、最小化、关闭前，把已累计的时间拆成不超过 15 秒的 `tick` 送出，然后停止。回到前台只继续计时，不再算一次新的打开。

同一次访问、同一天、同一小时只更新一行。

分享不存在或已停用返回 404。访问记录与当前设备或当前分享对不上，返回 400。早于保留期限的事件不写入。

## Storage

两张新表，不写入视频的访问表和播放表。

- 阅读访问：设备、分享 token、书库路径、文件名快照、开始时间、最后出现时间、IP、User-Agent、设备名。
- 阅读汇总：同一次访问、同一天、同一小时一行，含阅读秒数和打开次数。

## Query

`GET /api/v1/share/read-stats?from=YYYY-MM-DD&to=YYYY-MM-DD` 需要 `X-API-Key`（服务配置了密钥时）。缺省日期为最近 7 天（含今天）。日期无效或起止颠倒返回 400。

只返回这段时间里有阅读记录的设备。每台设备包含：

- `id`、`device_label`、`last_ip`、`user_agent`、`allowed`、`read_sec`
- `by_day`：当天阅读秒数、最早开始、最晚仍在读、0–23 点各小时秒数
- `hot_books`：书库路径、文件名快照、阅读秒数、打开次数，按阅读时长排序

`allowed` 和视频共用。关掉后这台设备不能再打开分享图书，也不能再记新的阅读。这个接口本身不能修改开关。视频统计接口的返回不变。

## Retention

阅读访问和阅读汇总只保留最近一个月，起点与视频相同：上个月的同一天，该月没有这一天时用该月最后一天。更早的行在服务启动、上报阅读事件（最多每 6 小时一次）和查询阅读统计时删除。设备行和 `allowed` 不因过期删除。视频记录的清理规则不变。

## AI

MCP 工具 `share_read_stats(from_date, to_date)` 调用上述查询接口。说明中写明：用设备名和 IP 区分阅读者，不要自行把某台设备说成某个孩子。

`share_watch_stats` 与 `set_share_device_access` 保持原样。

## Tests

- 同一 `fmc_visitor` 下，视频设备和阅读设备是同一行。
- 一次打开只计一次；前台 5 秒计入；单次 20 秒的 `tick` 不计入；页面前台以外的时间不计入。
- 小时按服务器本地时间归桶。
- 书架列表和管理页阅读不上报。
- 早于保留期限的阅读记录在查询后消失，设备行仍在。
- 日期颠倒返回 400。
- 被禁止的设备打不开分享书架和阅读页，书的文件返回 403，也不会再记新的阅读。
