# 电子书分享书架与阅读页

Date: 2026-11-05  
Product: family-mediacenter  
Status: approved

## Goal

可以把书库里的一个目录或一本电子书发成独立链接。目录分享是书架：先看到书，再点进阅读。单本分享打开就是那一本。

## Public pages

管理端的电子图书页保持「目录 + 右侧阅读」，不给访客用。

### 书架 `/shelf/{token}`

- 顶栏是书架名。目录有 `meta.json` 时显示简介和作者。
- 正文是封面网格。当前目录里的子文件夹和电子书都列出。
- 点子文件夹进入下一层。面包屑第一级是这次分享的书架名，不能退到分享目录之外，也不能回到整个书库。
- 点书进入 `/shelf/{token}/read?path=相对分享根的路径`。
- 不提供下载，不显示磁盘路径，不给出 `/files/` 地址。

### 阅读

- 从书架进入时，顶栏左侧是「返回书架」，回到进入阅读前的那一层。标题是书名。正文占满剩余区域，沿用现有阅读器的翻页、滚动和缩放。
- 单本分享是 `/book/{token}`。打开即阅读，没有返回书架。

手机上书架为单列。阅读页同样铺满屏幕。

## Share record

一张表，一个路径最多一条分享：

- `token`：公开地址里的随机串
- `sub_path`：相对书库根的目录或文件
- `is_dir`：目录还是单本
- `enabled`：是否有效

管理端在电子图书页对当前目录或选中的书提供：发布、复制链接、重置链接、停止分享。这些接口需要 API 密钥（若已配置）。再次发布同一路径时沿用原链接，除非重置。

停止或重置后，旧的书架页和阅读页返回「分享不存在或已停用」。目录或文件被删掉时同样打不开。

## File access

书架列表、封面和阅读器只使用分享地址：

- `GET /api/v1/shelf/{token}?path=` 列出分享根之内的一层
- `GET /api/v1/book/{token}` 返回单本信息
- `GET /api/v1/shelf/{token}/file?path=` 与 `GET /api/v1/book/{token}/file` 读取文件

`path` 规范化之后必须等于分享目标，或位于分享目录里面。封面如果在该目录内，也走这个文件地址。分享响应里不出现 `/files/`。

支持的书仍是 `.md`、`.pdf`、`.epub`、`.txt`。`meta.json` 和点开头的文件不出现在书架上。

## Out of scope

- 观看统计、设备允许开关
- 分享页下载或复制原始文件链接
- 改动管理端自己的阅读布局
